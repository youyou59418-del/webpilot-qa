# Demo sequence

1. Start ShopBench, FastAPI/Worker, then the Day 9 console.
2. Create a search-and-cart run and show planned steps, trace, verifier evidence and screenshot.
3. Trigger a controlled dynamic DOM change to show bounded recovery/self-healing evidence.
4. Create a high-risk checkout-confirmation run; show approval required before the action reaches the page.
5. Run Day 11 on a small fixed task slice and open its archived report.
6. Generate a Day 12 regression test from a verified, non-sensitive trajectory and repeat it three times.

Never use a real account, payment instrument, or destructive production action in the demo.
